UserAPI Documentation

A full-featured Telegram Bot API replica powered by Telethon and FastAPI, seamlessly routing bot requests to real Telegram user accounts.

🚀 Quick Start Flow

1. Register Session

Upload a .session file or provide a StringSession along with your api_id and api_hash.

curl -X POST "http://localhost:8000/auth/register" \
  -F "file=@my_account.session" \
  -F "api_id=1234567" \
  -F "api_hash=0123456789abcdef0123456789abcdef"

2. Get User Token

The server assigns you a secure, unique user token formatted as:

{
  "ok": true,
  "result": {
    "token": "usr_94b5e28a01...",
    "user": { "id": 12345, "first_name": "Alex" }
  }
}

3. Call Bot API

Call endpoints exactly like the Telegram Bot API using /{token}/ or /bot{token}/.

curl -X POST "http://localhost:8000/bot/sendMessage" \
  -H "Content-Type: application/json" \
  -d '{"chat_id": "@channel", "text": "Hello!"}'

🌐 Proxy Configuration (MTProto, SOCKS5, HTTP)

Each user session can have its own dedicated proxy. You can supply proxy settings upon registration or configure them on the fly:

SOCKS5 / HTTP Proxy

Configure a SOCKS5 or HTTP proxy dynamically:

curl -X POST "http://localhost:8000/bot/setProxy" \
  -H "Content-Type: application/json" \
  -d '{
    "proxy": "socks5://user:pass@1.2.3.4:1080"
  }'

MTProto Proxy

Native Telegram MTProto randomized intermediate proxy:

curl -X POST "http://localhost:8000/bot/setProxy" \
  -H "Content-Type: application/json" \
  -d '{
    "proxy": {
      "type": "mtproto",
      "host": "proxy.server.com",
      "port": 443,
      "secret": "dd00000000000000000000000000000000"
    }
  }'

🤖 Official Telegram Bot Reverse Proxy with Proxy Relay

UserAPI can also serve as an intelligent proxy middleman for official Telegram bots created via @BotFather. Connect bots through SOCKS5 or HTTP proxies to bypass censorship or network filters:

1. Register Bot or Call On-the-Fly

Register your BotFather token or call directly with /bot<TOKEN>/<METHOD>:

curl -X POST "http://localhost:8000/auth/register_bot" \
  -H "Content-Type: application/json" \
  -d '{
    "bot_token": "123456789:AAFxxx...",
    "proxy": "socks5://user:pass@127.0.0.1:1080"
  }'

2. Configure Bot Proxy Dynamically

Set, inspect, or delete proxies for any bot token:

# Set Proxy
curl -X POST "http://localhost:8000/bot/setProxy" \
  -H "Content-Type: application/json" \
  -d '{"proxy": "socks5://127.0.0.1:1080"}'

# Delete Proxy
curl -X POST "http://localhost:8000/bot/deleteProxy"

🔄 Token Rotation & Session Lifecycle (Unlink vs Terminate)

Rotate API Token

Regenerate or customize your API token without re-logging in or losing session state:

curl -X POST "http://localhost:8000/bot/rotateToken" \
  -H "Content-Type: application/json" \
  -d '{"new_token": "optional_custom_token"}'

Unlink from Server Only

Removes session files and tokens from the server WITHOUT logging out of Telegram (session stays active on your phone):

curl -X POST "http://localhost:8000/bot/unlink"
# Or standard Telegram method:
curl -X POST "http://localhost:8000/bot/close"

Terminate Telegram Session

Completely logs out from Telegram servers (terminating session) and wipes local server data:

curl -X POST "http://localhost:8000/bot/terminate"
# Or standard Telegram method:
curl -X POST "http://localhost:8000/bot/logOut"

💾 Session Export & Backup

Export Session File (.session)

Download the authentic Telethon SQLite .session binary file for your account:

curl -O -J "http://localhost:8000/session/export_file?token=usr_xxxx"
# Or Bot API method:
curl -X POST "http://localhost:8000/bot/exportFile"

Export StringSession & Metadata

Retrieve StringSession, API credentials, and account details in JSON:

curl "http://localhost:8000/session/export?token=usr_xxxx"
# Or Bot API method:
curl -X POST "http://localhost:8000/bot/exportSession"

Export Full ZIP Backup

Download a complete ZIP archive containing the .session file and session_info.json:

curl -O -J "http://localhost:8000/session/export_all?token=usr_xxxx"

📁 File Upload, Download & Media Parity

getFile & File Download

Get file metadata and download files directly via standard Bot API file path:

# 1. Get file path
curl -X POST "http://localhost:8000/bot/getFile" \
  -H "Content-Type: application/json" \
  -d '{"file_id": "msg_12345_doc"}'

# 2. Download file
curl -O "http://localhost:8000/file/bot/"

Rich Media & Extended Bot API

Full parity with Bot API media & interaction methods:

  • sendMediaGroup: Send albums of photos and videos
  • sendPoll: Create regular or quiz polls
  • sendDice: Send animated dice / darts / basketball
  • setMessageReaction: Add emoji reactions to messages
  • banChatMember & unbanChatMember

Public Proxy Tester

Public latency and connectivity test endpoint (no token required):

curl "http://localhost:8000/proxy/test?proxy=socks5://127.0.0.1:1080"
# Returns:
# {"ok": true, "result": {"alive": true, "latency_ms": 42.5}}

🛡️ Admin Dashboard & Storage Quota

Admin Authentication

Set ADMIN_TOKEN in .env to access management endpoints via X-Admin-Token or Authorization: Bearer <token>.

curl -H "X-Admin-Token: your_secret_admin_token" \
  "http://localhost:8000/admin/stats"

Manage Sessions & Quotas

Inspect all registered sessions, view storage used, or update quotas per user:

# List all sessions:
curl -H "X-Admin-Token: secret" "http://localhost:8000/admin/sessions"

# Update storage quota (MB):
curl -X PUT -H "X-Admin-Token: secret" \
  "http://localhost:8000/admin/sessions//quota?quota_mb=200"

📊 Feature Compatibility Matrix

Method / Feature Status Notes & Telethon Userbot Translation
getMe SUPPORTED Returns real user account details formatted as standard Bot API User
sendMessage SUPPORTED Supports text, HTML/Markdown parse_mode, reply_to, schedule_date
sendPhoto, sendDocument, sendVideo SUPPORTED Supports multipart file uploads, URLs, and captions
forwardMessage, copyMessage SUPPORTED Copies or forwards messages across any accessible chats
editMessageText, editMessageCaption SUPPORTED Edits user's messages
deleteMessage, deleteMessages SUPPORTED Deletes individual or batch messages
pinChatMessage, unpinChatMessage SUPPORTED Pins and unpins messages
getChat, getChatAdministrators SUPPORTED Fetches chat details, members count, admin lists
sendMediaGroup SUPPORTED Sends multi-item photo/video media albums
sendPoll, sendDice, sendSticker SUPPORTED Full support for native Telegram polls, animated dice/darts, and stickers
setMessageReaction SUPPORTED Sets or clears emoji reactions on messages
getFile & /file/... SUPPORTED Retrieves file metadata & downloads directly through Bot API file URLs
uploadFile SUPPORTED Uploads files to user storage and returns reusable Bot API file_ids
setChatDescription, exportChatInviteLink SUPPORTED Manages chat descriptions and generates invite links
banChatMember, unbanChatMember SUPPORTED Kicks/bans and unbans chat participants
getUpdates & setWebhook SUPPORTED Buffered long-polling or webhook dispatch for incoming messages
joinChat USERBOT EXTENSION Joins public channels or private invite links (t.me/+hash)
getDialogs USERBOT EXTENSION Lists conversations, unread counters, and last messages
markAsRead USERBOT EXTENSION Marks incoming unread messages as read
setMyCommands, getMyCommands BOT-ONLY Returns 400 Bad Request with explanation: user accounts lack bot scopes
answerCallbackQuery BOT-ONLY Returns 400 Bad Request: user accounts do not receive inline button queries
Inline keyboards with callback_data BOT-ONLY Returns 400 Bad Request: user sessions cannot handle callback_data
Note on Bot-Only Restrictions: When a client attempts to use bot-exclusive features such as command menus, callback buttons, or invoice creation, UserAPI returns a compliant Telegram Bot API error JSON (e.g. {"ok": false, "error_code": 400, "description": "..."}) clearly explaining why Telegram user sessions cannot execute that action.
